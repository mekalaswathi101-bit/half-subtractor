# Half Subtractor using Verilog

## 📌 Project Description

This project implements a 1-bit Half Subtractor using Verilog HDL.

A Half Subtractor is a combinational digital circuit that performs the
subtraction of two single-bit binary numbers.

It has two inputs:

- A - Minuend
- B - Subtrahend

It produces two outputs:

- Difference
- Borrow

## 🎯 Objectives

- Design a Half Subtractor using Verilog HDL.
- Implement the logic equations.
- Create a Verilog testbench.
- Simulate all possible input combinations.
- Verify the outputs using a waveform.
- Upload the project to GitHub.
